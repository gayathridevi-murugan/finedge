ROOT CAUSE ANALYSIS
================================================================================

Zero Amount Payment Issue Sources:
1. Smart Shopping: Payment fails before amount check (no cartId)
2. NFC Self Checkout: Missing backend update endpoint allows sync issues
   - User changes qty in UI → Local state updates
   - Backend request fails (endpoint missing) → Backend unchanged
   - User navigates to payment
   - Payment reads local state (correct amount)
   - Order created from backend cart (old amount)
   - MISMATCH: Frontend amount ≠ Backend order amount

Quantity Initialization:
- SmartNFCShoppingDashboard: quantity = 1 ✓
- NFCSelfCheckout: quantity = 1 ✓
- Backend CartItem: quantity default = 1 ✓
All correctly initialized but quantity changes not persisted.
